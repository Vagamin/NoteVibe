# Отложенный прототип Яндекс Диска

Идея отменена пользователем. Эти файлы — архив незавершённого прототипа, а не активная часть NoteVibe.
Код Dart сохранён с расширением `.dart.disabled`: он не участвует в сборке или тестах.
Снимки update_service и update_card показывают точки интеграции; не заменяйте ими актуальные файлы целиком.

В архиве есть проверка Ed25519, подписанный манифест, резервная загрузка и инструменты публикации.
Сквозная проверка реальной публикации не выполнена. OAuth-токен не был настроен, файлы на Диск не загружались.
Закрытый ключ отсутствует в архиве и хранится только локально вне репозитория.
Не запускайте публикацию без нового явного решения пользователя. Старые инструкции сохранены только для справки.
