# Резерв обновлений на Яндекс Диске

Публичная папка: https://disk.yandex.ru/d/wGSbdk-DsW0JrQ

## Локальная настройка

1. Создайте OAuth-приложение Яндекса с доступом к API Диска (чтение и запись файлов). Авторизуйте владельца выделенной папки.
2. Не отправляйте токен в чат, не храните его в исходниках или аргументах команд. Для текущего PowerShell-сеанса введите его скрыто:

```powershell
$secret = Read-Host 'OAuth-токен Яндекс Диска' -AsSecureString
$env:YANDEX_DISK_TOKEN = [System.Net.NetworkCredential]::new('', $secret).Password
```

Токен существует только в окружении текущего процесса и его дочерних процессов; после публикации удалите его:

```powershell
Remove-Item Env:YANDEX_DISK_TOKEN
```

Закрытый ключ Ed25519: `%LOCALAPPDATA%\NoteVibe-Release\mirror-signing.seed`.
Сохраните его защищённую резервную копию. Не публикуйте ключ и не заменяйте его без обновления встроенного открытого ключа приложения.
OAuth-токен и ключ подписи — разные секреты. Публичное скачивание не требует OAuth.

## Публикация

Из корня проекта, после сборки и проверки релизных файлов:

```powershell
powershell -NoProfile -File tools/publish_yandex_mirror.ps1 -Version '1.6.2+94' -PrivateKeyPath "$env:LOCALAPPDATA\NoteVibe-Release\mirror-signing.seed" -RemoteFolder 'disk:/VibeNote'
```

Скрипт проверяет соответствие папки публичной ссылке, загружает неизменяемую папку версии, сверяет размер/SHA-256 по API Диска и последним публикует подписанный `latest.json`.
Если папка переименована, укажите актуальный `RemoteFolder` — публичная ссылка остаётся фиксированной.
Скрипт не публикует GitHub-релиз самостоятельно. Включайте проверку зеркала в процедуру выпуска, не считайте зеркало обновлённым при ошибке скрипта.

Манифест действителен 365 дней. До истечения срока выпустите новый манифест. Приложение отвергает просроченную подпись и неподходящие файлы.

## Поведение клиента

- GitHub основной. При временных сбоях проверки — подписанный манифест зеркала.
- Если GitHub сообщил релиз, но загрузка файла не удалась, резервный файл должен совпадать по полной версии, размеру и SHA-256.
- Скачивание с зеркала требует подтверждения пользователя. Перед установкой проверяются размер и SHA-256.
- Уже выпущенные версии без поддержки зеркала не получат её удалённо: первый переход выполняется обычным обновлением или вручную.

До реальной публикации обязательна сквозная проверка публичного манифеста, скачивания файла, отказа при подмене и отказа от установки пользователем.
