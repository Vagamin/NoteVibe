# NoteName: согласованный план изменений

Релиз не публикуется без отдельного согласования. Промежуточные установки на подключённый телефон разрешены пользователем.
Отметки означают реализацию; проверка поведения на реальных устройствах продолжается.

- [x] Локальные однократные Android-напоминания, разрешения и переход в заметку из уведомления (экран блокировки требует проверки на телефоне).
- [ ] Контрастные слои меню и верхних панелей, единые тени и затемнение.
- [x] Переход из уведомления об обновлении к подсвеченному разделу; действие «Позже».
- [x] Настройка удержания активного поля/курсора выше клавиатуры.
- [x] Синхронизируемые отображаемые имена вложений; локальная настройка разрешения редактирования.
- [x] Миниатюры изображений, выбор из галереи, плеер аудиовложений.
- [x] Цвет текста и выделения; горизонтальная прокрутка форматирования; единые рисованные значки 24×24.
- [x] Подавление фонового шума только в визуализации записи.
- [x] Новые пункты чек-листа не отмечены; выполненный текст приглушён.
- [x] Лимит вложений 100 МБ, включая галерею и входящую синхронизацию (лимит временного кэша остаётся 50 МБ).
- [ ] Разовая передача выбранных заметок по QR в одной LAN без постоянного сопряжения.
- [x] Новое постоянное сопряжение в «Устройствах»: только телефон ↔ ПК; проверка ролей в зашифрованном соединении до сохранения доверия. Ранее созданные пары сохранены. Для нового сопряжения обновить обе стороны.
- [x] Удаление дублирующего действия корзины на Windows, клавиша Delete.
- [x] Ссылка на GitHub при нажатии названия приложения в шапке.
- [ ] Пароль Windows и необязательное шифрование базы, вложений, временных файлов и резервных копий; безопасная миграция в обе стороны. В настройках пока только недоступный переключатель с явным статусом разработки, без запроса пароля и имитации миграции.
- [x] Переименование в NoteName и иконка из app-icon.png; идентификатор Android и пути данных сохранены. Промежуточная сборка 59 установлена поверх существующей.

Шифрование требует отдельной проверки формата, аварийного восстановления и миграции.
Не подменять шифрование простой блокировкой интерфейса и не оставлять открытые копии данных.
