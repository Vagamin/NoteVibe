# NoteVibe 1.0.0 — stable

Начало новой стабильной линии версий. Старые номера выпусков относятся к этапу разработки; схема базы и совместимость данных сохранены.

- Текстовые и голосовые заметки со встроенным плеером.
- Вложения до 50 МБ с проверкой целостности и загрузкой по запросу.
- Синхронизация по локальной сети без сервера, сопряжение устройств и зашифрованная передача.
- Важные заметки, архив, корзина и ручной порядок.
- Массовый выбор, настройки предпросмотра и размера текста.
- Обновлённый интерфейс Android и Windows, новый прозрачный значок.

Для перехода со старых выпусков 1.1–1.4 установите сборку вручную поверх приложения. Не удаляйте приложение: данные должны сохраняться при обновлении с той же подписью.

Новая функция повышает MINOR, исправление — PATCH, крупное несовместимое изменение — MAJOR.
