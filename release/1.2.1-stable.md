# NoteVibe 1.2.1 — stable

- Поиск заметок скрыт под значком лупы в верхней панели и открывается по нажатию.
- Крестик закрывает поиск и сбрасывает фильтр. Название приложения и остальные действия остаются на месте.
- На Windows сочетание Ctrl+F открывает поиск и переводит фокус в поле ввода.

Android и Windows. Устанавливайте поверх предыдущей версии без удаления приложения.
