# NoteVibe 1.3.0 — stable

- До 10 голосовых записей в одной заметке. Длительность каждой — до 5 минут.
- Предпросмотр голосовых: только количество, от 1 до 10 записей или все записи. Существующий выбор сохраняется.
- Более плавная волна записи с расчётом по средней энергии звука и затуханием при отсутствии свежего сигнала; исправлено залипание после слова.
- На Windows повышена чувствительность визуализации тихой речи. Поведение Android сохранено.
- Компактнее заголовок блока записей; устранены лишние отступы вокруг него.
- Отступ перед первой заметкой согласован с расстоянием между карточками.

Android и Windows. Устанавливайте поверх предыдущей версии без удаления приложения.
