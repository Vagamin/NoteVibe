# NoteVibe 1.3.4 — stable

- Загруженные обновления проверяются по SHA-256 из GitHub Releases. Повреждённый файл, даже совпадающий по размеру, скачивается заново.
- Перед началом скачивания повторно запрашивается последний стабильный релиз: пропущенные версии не нужно устанавливать по очереди.
- Перед открытием установщика Android проверяется читаемость APK и принадлежность пакета NoteVibe; передача доступа к файлу дополнена ClipData.

Android и Windows. Устанавливайте поверх предыдущей версии без удаления приложения.
