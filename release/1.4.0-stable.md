# NoteVibe 1.4.0

Существующие заметки, данные и сопряжения сохраняются: удалять прежнее приложение не нужно.

## Новое
- Разовая зашифрованная передача выбранных заметок по QR без постоянного сопряжения. Прогресс передачи, объём данных и заметное подтверждение результата на обоих устройствах.
- Необязательное шифрование хранилища Windows паролем: база, вложения, внутренние резервные копии и ключи синхронизации. Проверенный перенос при включении и отключении, смена пароля и восстановление прерванного переноса.
- Однократные напоминания прочитать заметку на Android с системным будильником и вводом времени цифрами.
- Собственные названия вложений с синхронизацией, миниатюры изображений и выбор фотографий из галереи.
- Лимит вложения увеличен до 100 МБ.

## Интерфейс
- Новый значок; ссылка на GitHub в названии приложения.
- Цвет текста, выделение и форматирование видны в карточках заметок.
- Восемь размеров шрифта, применяемых также к спискам и заголовкам редактора.
- Обновлённая панель форматирования, индикаторы текущих цветов, исправления чек-листов и видимости курсора над клавиатурой.
- Компактный блок временных файлов, улучшенные панели камеры, QR и напоминаний.
- Заметная панель доступного обновления в цветах приложения, без автоматического исчезновения.

## Важно
- Для нового сопряжения и разовой передачи обновите оба устройства. Постоянное сопряжение предназначено для телефона и ПК.
- Шифрование Windows не шифрует копии на телефоне. До разблокировки ПК синхронизация недоступна. Забытый пароль восстановить нельзя.
- Сохранённые пользователем открытые копии файлов, системные резервные копии, дампы и файл подкачки не входят в защиту хранилища. Удаление прежних файлов не гарантирует физического стирания с SSD.
- Для Android-напоминаний разрешите уведомления и точные будильники. После системного «Остановить принудительно» требуется снова открыть приложение; ограничения энергосбережения производителя также могут влиять на доставку.

## Установка
- **Android:** установите подходящий APK поверх текущего приложения. Для большинства телефонов — `arm64.apk`.
- **Windows:** скачайте `portable.exe`, сохранив прежнюю папку `NoteVibe-Data`. Внутренние пути оставлены совместимыми.
