# NoteVibe 1.4.1

- Исправлен лишний верхний отступ на Android: область строки состояния больше не создаётся дважды, панель приложения снова располагается правильно.
- В меню вложений рядом с «Сохранить копию» добавлено «Копировать в буфер обмена». Копируется сам файл: Android использует системный URI, Windows — список файлов для вставки в совместимые приложения.
- При копировании из зашифрованного хранилища показывается предупреждение о доступе других приложений к открытой копии.

Устанавливайте поверх предыдущей версии. Заметки и настройки сохраняются.
