# NoteVibe 1.5.0

- Защита данных паролем на Android: зашифрованные база, вложения, резервные поколения и ключи синхронизации. Включение и отключение выполняются с проверкой переноса.
- Вход по отпечатку через Android Keystore (Android 9 и новее, при наличии совместимой сильной биометрии). Пароль остаётся запасным способом входа; после его изменения биометрию нужно подключить заново.
- При сворачивании защищённого приложения включается блокировка, останавливаются сетевые соединения и воспроизведение. Снимки экрана запрещены; напоминания не раскрывают заголовки заметок.
- Сохранение полного файла SQLite доступно при включённом шифровании после повторного ввода пароля. Копия не зашифрована, отдельные файлы вложений в неё не входят.
- Проверка обновлений при запуске и возвращении в приложение, не чаще одного запроса за пять минут.
- Исправлены правила запуска Android для уменьшения дублирования карточек в недавних приложениях, включая запуск из уведомлений.

Сохраните пароль: восстановление невозможно. Внешние экспорты и системные резервные копии не входят в гарантии хранилища. При блокировке в фоне разблокированная сессия остаётся в памяти процесса; на диске данные зашифрованы.

Устанавливайте поверх текущей версии, без удаления приложения.
