# NoteVibe 1.5.3

- Резервная копия в одном ZIP: полный файл базы и доступные локально вложения. Архив не зашифрован; в защищённом режиме требуется повторный ввод пароля.
- Импорт ZIP NoteVibe и ранее сохранённых файлов .db с выбором: добавить независимые копии или заменить все текущие заметки, включая архив и корзину. Настройки и сопряжения устройства сохраняются.
- Перед импортом обязательно сохраняется страховочный ZIP в выбранное пользователем место. При отмене сохранения импорт не начинается.
- Проверка целостности SQLite, контрольных сумм архива и вложений перед изменением заметок. Данные заметок импортируются одной транзакцией.

Копии не защищены паролем: храните их в безопасном месте. Отсутствующие на устройстве вложения в ZIP не входят, файл .db не содержит файлов вложений. Максимальный размер копии — 512 МБ. Поддерживаются ZIP, созданные NoteVibe, без ручной перепаковки.

При замене изменения синхронизируются с сопряжёнными устройствами. Устанавливайте обновление поверх текущей версии, без удаления приложения.
