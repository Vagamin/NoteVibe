# NoteVibe 1.5.4

- Убран дублирующий экспорт базы из блока защиты паролем. Все операции с копиями находятся в разделе «Резервные копии».
- Импорт и экспорт доступны только при включённой защите данных паролем и требуют повторного подтверждения пароля. Без защиты кнопки отключены, рядом показано пояснение.
- Формат копий не изменён: ZIP и прежние файлы .db остаются незашифрованными.

Устанавливайте поверх текущей версии, без удаления приложения.
