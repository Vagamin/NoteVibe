# NoteVibe 1.6.0

- Блоки программного кода в обычных заметках: отдельное окно редактирования, моноширинный шрифт, сохранение пробелов, табуляции и переносов при сохранении и копировании.
- Базовая подсветка кода в заметке и окне редактирования. Блоки кода и подсветку можно отключить в настройках.
- Автоопределение Python, SQL, TypeScript, JavaScript, Dart, C#, Java, C/C++, HTML/XML, Rust, Go, Kotlin, Swift, PHP, Ruby, Bash/Shell, PowerShell и CSS. Распознанный язык отображается в сведениях о заметке; определение приблизительное.
- Компактная плашка «Есть программный код» вместо предпросмотра исходников в карточке. Плашка и окно кода учитывают настройку размера заметок.
- Кнопка удаления всех блоков кода в панели форматирования появляется только при наличии кода. Удаление требует подтверждения и сохраняет обычный текст.
- Полный длинный заголовок доступен по удержанию карточки, на ПК — также по наведению. В открытой заметке есть отдельная кнопка раскрытия без конфликта с выделением текста.
- Более компактное оформление заголовка, блока кода и кнопок создания заметок на ПК. Обновлено меню напоминаний, активное напоминание обозначается заполненным колокольчиком.
- Улучшена обработка действия «Назад» в режимах выбора, поиска и разовой передачи.
- Windows: постоянное имя portable-файла — NoteVibe.exe. При обновлении со старого имени папка NoteVibe-Data сохраняется; ярлыки со старым именем потребуется пересоздать один раз.

Для обычного запуска Windows скачивайте **NoteVibe.exe**. Файл **NoteVibe-1.6.0-portable.exe** содержит ту же сборку и оставлен для совместимости со старым механизмом обновления. Переход на постоянное имя выполняется новым механизмом обновления, начиная с этой версии.

Устанавливайте обновление поверх текущей версии, без удаления приложения. Перед обновлением рекомендуется создать резервную копию.
