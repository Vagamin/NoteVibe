# NoteVibe 1.6.1

- Независимые блоки кода в одной заметке: чередуйте обычный текст и код в любом порядке. После вставки блока курсор переходит на обычную строку ниже.
- Каждый блок можно свернуть в компактную плашку с распознанным языком и развернуть обратно. Исправлен мигающий курсор поверх плашки при сворачивании.
- Меню отдельного блока: редактирование, копирование исходного текста и удаление с подтверждением. Обычный текст и остальные блоки сохраняются.
- Совместимый формат хранения: существующие заметки открываются без миграции, код сохраняется обычными Quill code-block строками. Состояние сворачивания действует в текущем открытом редакторе.
- При переходе из уведомления об обновлении подсвечивается весь раздел, а найденная версия сразу доступна для установки без повторной ручной проверки.
- При сбое загрузки отображаются причина и номер повторной попытки. На Windows перед заменой EXE и перезапуском запрашивается подтверждение.
- Windows: обновление из 1.6.0 переходит на постоянное имя NoteVibe.exe. Папка NoteVibe-Data остаётся на месте; ярлыки со старым именем нужно пересоздать один раз.

Для запуска на Windows скачивайте **NoteVibe.exe**. Дополнительный файл **NoteVibe-1.6.1-portable.exe** оставлен для совместимости с более старыми версиями обновления.

Устанавливайте поверх текущей версии, без удаления приложения. Перед обновлением рекомендуется создать резервную копию.
