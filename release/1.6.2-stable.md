# NoteVibe 1.6.2

- Исправлена каретка высотой с блок кода: курсор скрывается на строке блока, включая свёрнутое состояние, и возвращается при редактировании обычного текста.
- Оптимизированы большие блоки: подсветка и определение языка не пересчитываются для неизменившегося содержимого при перестроении редактора, отрисовка кода изолирована от окружающего интерфейса.
- Убран лишний разбор документа при автосохранении. Сохранены исходный код, отступы, подсветка, масштабирование текста и все действия с блоками.

Устанавливайте поверх текущей версии, без удаления приложения. Перед обновлением рекомендуется создать резервную копию.

Windows: основной файл — **NoteVibe.exe**. Файл **NoteVibe-1.6.2-portable.exe** содержит ту же сборку и оставлен для совместимости со старым механизмом обновления. При переходе со старого имени ярлыки потребуется пересоздать один раз; папка NoteVibe-Data остаётся на месте.
