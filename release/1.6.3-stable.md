# NoteVibe 1.6.3

- Исправлены скачки ползунка при прокрутке длинных заметок и раскрытых блоков кода.
- В длинной заметке появилась кнопка «В начало заметки».
- Уменьшена подсветка кнопки сворачивания и разворачивания кода; область нажатия остаётся удобной.
- Карточки обновлений в настройках теперь той же ширины, что и остальные. При переходе из уведомления подсвечиваются контуры карточек и заголовок вместо сплошной подложки.
- Добавлены повторные попытки проверки обновлений при временных ошибках GitHub и более понятные сообщения о недоступности сервиса.
- Перед установкой повторно проверяется, что версия действительно новее текущей.

Устанавливайте поверх текущей версии, без удаления приложения. Данные и формат заметок сохраняются. Перед обновлением рекомендуется резервная копия.

Windows: основной файл — **NoteVibe.exe**. **NoteVibe-1.6.3-portable.exe** содержит ту же сборку для совместимости со старыми обновляторами. Сохраните папку NoteVibe-Data рядом с приложением.

Android: arm64 — для большинства современных телефонов, armeabi-v7a — для 32-битных устройств, x86_64 — для соответствующих устройств и эмуляторов. Внутренний номер сборки 2094 обеспечивает обновление поверх ранее установленных тестовых сборок.

Обновления загружаются только с GitHub. Яндекс Диск не подключён. Демо-режим в релизе отключён.
