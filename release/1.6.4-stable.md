# NoteVibe 1.6.4

- Заметка запоминает, какие блоки кода были свёрнуты, и восстанавливает их состояние при повторном открытии. Это локальная настройка представления; текст и формат заметок не меняются.
- Добавлен ограниченный кэш подсветки кода для ускорения повторного открытия заметок. Свёрнутые блоки не отрисовывают полный текст кода.
- Начало и конец текста заметки обозначены тонкими линиями. В настройках можно отключить линии, выбрать короткие линии по центру или на всю ширину, а также показывать обе границы, только начало либо только конец.
- Уменьшен лишний пустой отступ между текстом заметки и вложениями.
- Проверена постановка курсора в выбранную позицию мышью и касанием.

Устанавливайте поверх текущей версии, без удаления приложения. Данные и формат заметок сохраняются. Перед обновлением рекомендуется резервная копия.

Windows: основной файл — **NoteVibe.exe**. **NoteVibe-1.6.4-portable.exe** содержит ту же сборку для совместимости со старыми обновляторами. Сохраните папку NoteVibe-Data рядом с приложением.

Android: arm64 — для большинства современных телефонов, armeabi-v7a — для 32-битных устройств, x86_64 — для соответствующих устройств и эмуляторов.

Обновления загружаются только с GitHub. Демо-режим в релизе отключён.
