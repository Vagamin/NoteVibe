# NoteVibe 1.6.5

- Кнопка навигации по длинной заметке теперь работает в обе стороны: вверху отправляет в конец, после прокрутки вниз — в начало.
- Убраны повторные преобразования всего кода при построении редактора. Содержимое для окна сведений подготавливается только при его открытии.
- Уменьшено количество временных объектов при подготовке больших блоков кода и обычного текста.
- Добавлен ограниченный кэш определения языка кода для повторного открытия заметок.

Код, отступы, пустые строки и формат заметок сохраняются; подсветка не ограничивается первыми строками. Очень большие раскрытые блоки всё ещё требуют времени на расчёт размеров и отрисовку.

Устанавливайте поверх текущей версии, без удаления приложения. Перед обновлением рекомендуется резервная копия.

Windows: основной файл — **NoteVibe.exe**. **NoteVibe-1.6.5-portable.exe** содержит ту же сборку для совместимости со старыми обновляторами. Сохраните папку NoteVibe-Data рядом с приложением.

Android: arm64 — для большинства современных телефонов, armeabi-v7a — для 32-битных устройств, x86_64 — для соответствующих устройств и эмуляторов.

Обновления загружаются только с GitHub. Демо-режим в релизе отключён.
