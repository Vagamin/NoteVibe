# NoteVibe 1.6.6

- Исправлен медленный поиск при определении языка длинного кода без фигурных скобок. Это устраняет найденную причину задержки первого открытия после перезапуска приложения.
- Исправлено копирование выделенного текста и блоков кода сочетанием Ctrl+C с сохранением отступов.
- Кнопка перехода в начало или конец заметки перенесена справа от панели форматирования. Её высота и оформление совпадают с панелью; подсветка покрывает всю кнопку, текст не перекрывается.
- Устранён запрос клавиатуры редактора при сворачивании и разворачивании кода.
- Настройки границ заметки объединены: отключены, обе, только начало или только конец. Линии отображаются на всю ширину.
- Подсветка пунктов меню вложений, кода, устройств и навигации теперь имеет скруглённые углы.

Содержимое заметок, код, отступы и формат хранения сохраняются. Очень большие раскрытые блоки по-прежнему требуют времени на расчёт размеров и отрисовку.

Устанавливайте поверх текущей версии, без удаления приложения. Перед обновлением рекомендуется резервная копия.

Windows: основной файл — **NoteVibe.exe**. **NoteVibe-1.6.6-portable.exe** содержит ту же сборку для старых обновляторов. Сохраните папку NoteVibe-Data рядом с приложением.

Android: arm64 — для большинства современных телефонов, armeabi-v7a — для 32-битных устройств, x86_64 — для соответствующих устройств и эмуляторов.

Обновления загружаются только с GitHub. Демо-режим и создание тестовых заметок в релизе отключены.
